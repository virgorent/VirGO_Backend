# docs/

Documentación transversal del monorepo que no pertenece a un proyecto concreto.

- `Modelo de datos VirGo.md` vive en la raíz.
- Los diseños exportados de Figma pueden ir en `docs/design/` como PNG o PDF.
- No guardar secretos, tokens ni datos personales.
- La documentación de cada proyecto vive en su propia carpeta (`VirGo-API/`, `VirGo-Database/`).
- [`PRUEBAS.md`](PRUEBAS.md): estado y resultados de las pruebas de los tres proyectos.
- [`ESTADO-PROYECTO.md`](ESTADO-PROYECTO.md): resumen del avance de los tres proyectos.
- [`backend/MAPA-SPECS.md`](backend/MAPA-SPECS.md) y [`backend/ENDPOINTS.md`](backend/ENDPOINTS.md): specs y endpoints de API y base de datos.
- [`ANALISIS-PROYECTO.md`](ANALISIS-PROYECTO.md): análisis spec por spec, endpoint por endpoint y archivo por archivo.

- Los specs de Móvil están en [`virgorent/VirGO_Movil`](https://github.com/virgorent/VirGO_Movil/tree/main/VirGo-Movil/specs).

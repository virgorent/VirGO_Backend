# VIRGO APP · Backend

**VirGo** connects people organizing an event with venues and service providers. This repository contains the **backend**.

| Project | Folder | Stack |
|---|---|---|
| Backend API | [`VirGo-API/`](VirGo-API/README.md) | .NET 10, AWS Lambda, MongoDB Atlas |
| Database | [`VirGo-Database/`](VirGo-Database/README.md) | Node.js, MongoDB Atlas |

The Android app lives in [`virgorent/VirGO_Movil`](https://github.com/virgorent/VirGO_Movil). Global SDD rules are in [`constitution.md`](constitution.md) and [`AGENTS.md`](AGENTS.md); they are kept aligned with the mobile repository. The shared data model is in [`Modelo de datos VirGo.md`](Modelo%20de%20datos%20VirGo.md). Project documentation is written in Spanish.

Test status and results: [`docs/PRUEBAS.md`](docs/PRUEBAS.md). Project status: [`docs/ESTADO-PROYECTO.md`](docs/ESTADO-PROYECTO.md).
